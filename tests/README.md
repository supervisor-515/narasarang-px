테스트 실행

```sh
npm ci
npm test
```

Node.js 22.12 이상을 사용한다. jsdom은 DOM 통합 테스트 전용 개발 의존성이다. 사이트는 기존처럼 빌드 없이 정적 파일로 실행한다.

- examples.test.js: 기존 예시, 100만원 상한, 조건·동률·10일·구간 힌트 회귀 검증
- v2.test.js: 명세 A–E, 월/일/연 경계, 급여이체 횟수, 구간 독립, 특별할인 분리, 보유 카드, 백업 검증
- v3.test.js: SPEC_V3 7대 검증 케이스(보정 구간 분리, 역순 기록 재계산, 10일 자동 적용, 동률·근소차 희소성 우선, 순이익 구간 힌트, 자격 게이트, 마이그레이션 및 금액대 카드표)
- ui.test.js: 일반 입력, 탭 전환, 결제 기록 및 중복 저장 차단·실행 취소, 과거 날짜 기록, 삭제, 설정 저장/복원, 오류 상태
- compare.test.js: 이번 결제에 쓸 카드 일시 제외(순위·기록 선택지·저장 시 초기화·전부 제외 안내), 물건별 계산(합계 연동·직접 입력 분리·재연결·삭제·상한)

기록에는 사실(id, 일자, 금액, 카드ID, 특별할인 적용 여부, 입력 순서)만 저장한다. 혜택(benefit)은 더 이상 정적으로 고정하지 않고, 집계 및 표시 시점에 날짜순(같은 날은 입력순)으로 전체 기록을 재생(replayRecords)하여 동적으로 재계산한다. 과거 기록을 추가·수정·삭제하면 이후 기록의 혜택과 잔여 한도가 자동으로 정합성을 갖춘다. 보유 해제한 카드의 이전 기록도 집계 데이터에 남는다.

실제 모바일 키보드, 파일 다운로드/파일 선택 UI, 서비스 워커 오프라인 동작은 실기기 확인이 필요하다.
